# Session fonts

These unmodified WOFF2 font files are redistributed under the SIL Open Font License 1.1. Each family directory contains its complete upstream OFL.txt and SHA256SUMS. Sources and the pinned Google Fonts license revision are recorded in sources.json.

Alegreya Sans supplies Latin and Cyrillic text. Baloo Bhaijaan 2 supplies Arabic, M PLUS Rounded 1c Japanese, and the regional Noto Sans families simplified Chinese, traditional Chinese and Korean. Other published character subsets in these families are preserved.

Font-face rules are in src/assets/session-fonts/. Unicode ranges preserve the publisher's partitions so browsers request the glyph subsets needed by the displayed text. Non-default families load on selection through Bable Fish. All runtime URLs are same-origin; no font CDN or external stylesheet is required.

Do not rename the fonts internally or remove their licenses. Preserve font-file hashes when redistributing these assets.
